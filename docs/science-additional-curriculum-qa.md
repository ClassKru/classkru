# ผลตรวจชุดผลการเรียนรู้วิทยาศาสตร์เพิ่มเติม

ตรวจเมื่อ 30 ตุลาคม 2569 จาก `SciCurriculum_2560.pdf` ที่ผู้ใช้ให้มา

## ผ่าน

- พบ 271 รายการ: ชีววิทยา 108, เคมี 96, ฟิสิกส์ 67
- รหัสรายการตรงกับดัชนีครบทุกข้อ ไม่มี ID ซ้ำ ข้อความว่าง หรือเลขข้อขาดใน 19 กลุ่มสาระ/ชั้น
- SQL seed ทั้ง 271 ข้อมีข้อความตรงกับ JSON ที่สกัด และไฟล์ SQL สำเนาทั้งสามชุดเหมือนกัน
- ปรับการต่อข้อความข้ามบรรทัด PDF และกันขีด `-` จากแถวคั่นชั้นไม่ให้ปนท้ายข้อความ
- ตรวจภาพหน้า PDF ตัวอย่าง 142, 146, 160, 175, 176, 196, 197 และ 227 ครอบคลุมชีววิทยา เคมี และฟิสิกส์; ข้อความที่สุ่มเทียบอยู่ในคอลัมน์ผลการเรียนรู้
- ตรวจฐาน Supabase production แบบอ่านอย่างเดียว: ยังไม่มี source นี้ ไม่มีแถวใน standards/units/outcomes/references ของ source นี้ และไม่มี outcome ID ที่ชนกัน
- ตาราง production ที่เกี่ยวข้องมีอยู่แล้ว; โครงสร้าง migration รองรับ seed นี้ จึงไม่ต้องเพิ่ม API schema
- Syntax JavaScript ผ่าน; ชุดทดสอบตรงกับงานนี้ผ่าน 5/5
- ทดสอบเต็ม staging ได้ 133 ผ่าน 11 ไม่ผ่าน; สำเนา production เดิมได้ 130 ผ่าน 11 ไม่ผ่าน และชื่อกรณีที่ไม่ผ่านทั้ง 11 ตรงกัน จึงไม่พบ regression จาก patch นี้

## ยังไม่อนุมัติให้ AI ใช้

ยังไม่ได้ตรวจเทียบทุกบรรทัดของทั้ง 271 ข้อกับ PDF ด้วยคนทีละรายการ จึงคงสถานะทุกข้อเป็น `unreviewed_automatic_pdf_extraction` และแหล่งข้อมูลเป็น `draft` ไว้ หน้าเว็บจะไม่โหลดรายการเหล่านี้จนกว่าจะเปลี่ยนสถานะโดยตั้งใจ

ยังไม่ได้แก้ฐาน production หรือ deploy โค้ด ชุด integration เป็น patch บน snapshot deployment เวลา 16:29; branch/worktree ปัจจุบันต่างจาก snapshot และมีงานแก้ค้างหลายไฟล์ ผลตรวจ `git apply --3way --check` ไม่ผ่านใน `curriculum-catalog.js`, `content-library.js` และ `scores.js` จึงห้ามนำ patch หรือ snapshot ไปทับตรง ๆ ต้องพอร์ตการเปลี่ยนแปลงเข้ากับโค้ดปัจจุบันโดยรักษางานเดิมก่อนปล่อย
