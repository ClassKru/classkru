# ชุดบรีฟและกฎกลาง Mini Lab V5

แต่ละโฟลเดอร์เลขลำดับเป็นชุดอิสระสำหรับปรับปรุงและทดลอง เลข 01 คือสำเนาจุดเริ่มต้นจากโค้ด V5 ก่อนปรับในแชทนี้ ไม่ได้หมายความว่าระบบเพิ่งผ่านการปรับครั้งแรก

เมื่อต้องการปรับรอบใหม่ ให้คัดลอกทั้งโฟลเดอร์ล่าสุดเป็นเลขถัดไป เช่น 02 แล้วแก้เฉพาะชุดใหม่นั้น เก็บไฟล์ทุกส่วนไว้ด้วยกัน เมื่อต้องการทดลองชุดใด ให้อ้างอิงไฟล์ในโฟลเดอร์เลขนั้นทั้งหมด และบันทึกสิ่งที่เปลี่ยนกับผลทดลองใน CHANGELOG.md ของชุดนั้น

- `กฎกลาง.md` สรุปกฎร่วมจากพรอมป์ปัจจุบัน พร้อมที่มาสำหรับตรวจสอบ ไม่ใช่พรอมป์แยกที่ระบบโหลด
- `architect-prompts.js` พรอมป์ Prompt Architect สำหรับแปลงบรีฟที่ยืนยันแล้วเป็นข้อกำหนดการสร้างสื่อ
- `conversation-prompts.js` และ `media-mode.js` พรอมป์การคุย รวมคำสั่งตามรูปแบบสื่อ
- `builder-prompts.js` พรอมป์สร้าง HTML
- `CHANGELOG.md` ที่มา การเปลี่ยนแปลง และผลทดลอง

เลือกชุดได้จากปุ่ม `ชุดบรีฟ` ข้างปุ่มตั้งค่า Lab ในหน้าเว็บ รายการแสดงโฟลเดอร์ที่ขึ้นต้นด้วยเลขและมีไฟล์พรอมป์ทั้งสาม `media-mode.js`, `กฎกลาง.md` และ `template-reference.js` ครบ (ชุด 01 ใช้ไฟล์อ้างอิงว่างเพื่อคงรูปแบบโฟลเดอร์เดียวกัน) เลือก `ระบบเดิม (services)` เพื่อกลับไปใช้พรอมป์เดิม การตั้งค่าถูกเก็บใน `.interactive-v5-local/brief-version.json` และมีผลกับการเรียก AI ครั้งถัดไป จึงควรเลือกก่อนเริ่มงานและไม่เปลี่ยนจนงานเสร็จ หากโฟลเดอร์ที่เลือกหายไปหรือมีไฟล์ไม่ครบ ระบบจะไม่สลับไปใช้ชุดอื่นโดยเงียบ ๆ ให้เลือกชุดที่พร้อมใช้งานใหม่

กฎกลาง.md เป็นเอกสารสรุปสำหรับคนอ่าน ไม่ได้ส่งให้ AI โดยอัตโนมัติ ข้อกำหนดที่ต้องการให้ AI ทำตามต้องอยู่ในพรอมป์ของขั้นที่เกี่ยวข้อง ชุดบรีฟเป็นโค้ด JavaScript ที่ระบบรันในเครื่อง จึงควรใช้เฉพาะไฟล์ที่เชื่อถือได้และรักษา interface `buildRequest` รวมถึง schema และข้อจำกัดของ V5 การแก้พรอมป์มีผลกับการเรียกครั้งถัดไป โหมด Mock ให้ผลจำลองและไม่สะท้อนผลของข้อความพรอมป์
